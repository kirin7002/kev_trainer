格式说明

每条样本需要 text（或 state）与标签；标签写在 intents / labels（字符串数组）或 expected_result.intents。也支持含明确布尔 label 的 Noul questions 格式。id 可选（默认自动生成），相同文本的标签必须一致。

[
  {"id": "case-00001", "text": "把客厅的灯调暗一点", "intents": ["灯"]},
  {"text": "空调和窗帘都关掉", "intents": ["空调", "窗帘"]},
  {"text": "今天天气怎么样", "intents": []}
]

JSONL：每行一个上述对象。CSV：表头 text,intents,id,group_id，多标签用 | 分隔，如 空调|窗帘；无对象必须显式填 []，空值会被视为缺失标签而拒绝（用于区分“缺失”与“显式无对象”）。

固定业务问题目录

任务 JSON 包含 name 与 objects 数组（1～100 项，每项 id、instructions、criteria）。criteria 为 true/false 描述对象。完整标注模式要求每条 Noul 样本标全目录；按明确问题标注模式只接受显式布尔 questions，未询问的问题不作为反例。

从训练池派生三个分区

只使用绑定任务的训练池，按会话/来源/模板/近重复关联组切分，不读取 test/regression。比例按组近似，至少需要三个独立组；派生版本保留父训练池原文件和切分记录。

创建实验

选择数据集与 Kev 模型版本。创建后由 Claude Code 基于训练/验证数据生成方案；最终测试集不提供给 Claude Code。

第一阶段：手动 0.8B 实验

独立选择训练、校准、验证和最终测试版本；回归集可选。所有分区必须绑定同一任务目录，关联组不能跨区。运行者显式启用并验证 CUDA Worker 后可执行训练；未接入时可检查输入和下载准备包。

已有方案准备流程

训练集与测试集不能包含相同文本或分组；训练集至少需要两个独立文本组才能留出验证集。

实验与方案

选择实验后由 Claude Code 在后台生成训练方案，可实时查看日志。方案就绪后可下载 plan.json。
